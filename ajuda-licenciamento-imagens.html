Ajuda:Licenciamento de imagens

Toda imagem ou ilustração publicada na TriânguloLeaks precisa ser de uso e distribuição livres, e precisa levar — junto dela, visível — uma linha de crédito dizendo qual é essa licença. Nenhuma imagem é aceita sem essa informação.

As duas categorias aceitas

CC0 / Domínio público

Ilustrações originais feitas para este projeto (os desenhos esquemáticos em SVG que aparecem nos artigos) são liberadas em CC0 — o autor abre mão de todos os direitos, e qualquer pessoa pode copiar, modificar e redistribuir livremente, inclusive para fins comerciais, sem pedir permissão nem dar crédito (embora dar crédito à TriânguloLeaks seja sempre bem-vindo).

CC BY-SA (ou outra licença livre compatível)

Fotografias reais trazidas de acervos externos livres — como o Wikimedia Commons — mantêm a licença original do arquivo (normalmente Creative Commons Atribuição-CompartilhaIgual, CC BY-SA) e o nome do autor/fonte, exatamente como exigido por essa licença. Usar uma imagem assim implica manter o crédito e, ao reutilizá-la, licenciar qualquer versão derivada sob a mesma licença.

Como isso aparece no site

Toda figura do site vem acompanhada de uma linha assim, logo abaixo da legenda:

Para uma foto real trazida de um acervo externo, a linha de crédito segue este formato:

CC BY-SA 4.0 Foto: Nome do autor, via Wikimedia Commons.

Regra para quem for adicionar uma imagem nova
  1. Confirme que a imagem tem uma licença livre (CC0, domínio público, ou CC BY/BY-SA) — nunca use uma imagem encontrada na internet sem essa confirmação.
  2. Inclua a imagem dentro de um <figure>, com <figcaption> descrevendo o que ela mostra.
  3. Logo abaixo, adicione um parágrafo <p class="credito-imagem"> com um <span class="selo-licenca"> indicando a licença, seguido do autor/fonte quando não for uma ilustração original do projeto.
  4. Nunca remova ou edite o crédito de uma imagem trazida de outro acervo — é uma condição da própria licença.

A TriânguloLeaks é um projeto independente, sem vínculo com a Fundação Wikimedia.
